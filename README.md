### 🧑‍💻 About me

I'm a developer learning web development at **HackYourFuture**, and I learn best by building real products.
I've built two full-stack platforms end to end: one is **live in production**, the other is in active development.
Both repositories are private, but here's the kind of work they involve:

- 🛒 **Marketplace and e-commerce:** catalogs, carts, checkout, orders, coupons, licensing and seller dashboards
- 💳 **Payments:** Stripe Checkout, webhooks, subscriptions and Stripe Connect payouts to sellers
- ⚡ **Real-time backends:** reactive queries, mutations, scheduled jobs and background workflows
- 🔐 **Authentication:** email, OAuth and passkey sign-in, roles and protected admin areas
- 🎧 **Media pipelines:** browser uploads, CDN delivery, HLS streaming, waveforms and transcoding
- 🔎 **Search:** full-text search with filters and facets
- ✉️ **Transactional email:** templated emails for orders, bookings and notifications
- 🤖 **AI features:** an in-app assistant with tool calling
- 📊 **Dashboards:** analytics, charts, data tables and admin tools
